## 13.最大数组和
``` java
class Solution {
    public int maxSubArray(int[] nums) {
        int preSum =0;  //前缀和
        int minpreSum = 0;//最小前缀和
        int ans =Integer.MIN_VALUE;//更新结果
        
        for(int num:nums){
            preSum += num;
            ans = Math.max(ans,preSum-minpreSum);
            minpreSum = Math.min(minpreSum,preSum);
        }
        return ans;
    }
}
```
### 思路
    * 计算连续数组的和，需要计算数组的__前缀和__从而将连续转为任意位置
    * 实现用的是 前缀和 + 最小前缀和 的方法
    * 最大子数组和可以通过 当前前缀和减去之前的最小前缀和 得到。

## 14.合并区间
``` java
class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals,(p,q) -> p[0]-q[0]);//按每个区间的 起点 从小到大排序
        List<int[]> ans = new ArrayList<>();//创建一个 List 来存储 合并后的区间。
        for(int[] p:intervals){
            int m =ans.size();//记录当前 ans 中已有的区间个数，用于获取最后一个已加入 ans 的区间
            if(m>0&&p[0]<=ans.get(m-1)[1]){  //判断当前区间的起点是否 小于等于 上一个区间的终点。
                ans.get(m-1)[1]=Math.max(ans.get(m-1)[1],p[1]);//更新终点
            }else{
                ans.add(p);
            }
        }
        return ans.toArray(new int[ans.size()][]);//转为二维数组返回
    }
}
```
### 思路
- 先排序再合并
- 遍历区间：
    - 如果当前区间与前一个区间重叠 → 合并。
    - 不重叠 → 直接加入。
### 总结 
```return ans.toArray(new int[ans.size()][]);``````toArray()```需要传入一个```int[][]``` 数组来接收结果
- Java 数组大小固定 而 List 可变，最开始设为List<int[]> ans，最后转为Array
- ```Arrays.sort(array)``` 默认按 自然顺序 排序（数字从小到大，字符串按字典序）。
- ```Arrays.sort(array, Comparator)```自定义比较规则，使用 比较器（Comparator）。
- ```(p, q) -> p[0] - q[0] ```是 Lambda 表达式，是 **compare** 方法的实现。
    - p 和 q 是数组 intervals 中的两个元素，也就是两个子区间（int[]）。
    - -> 表示“将左边的参数映射到右边的表达式结果”。
    - 右边 ```p[0] - q[0] ```表示 比较两个区间的起点：
        - 如果结果 < 0 → p 在前
        - 如果结果 = 0 → 两者顺序不变
        - 如果结果 > 0 → q 在前
    - 换句话说，这一行就是告诉 Java：“请按每个区间的 起点 从小到大排序。”

## 15.轮转数组#
``` java
class Solution {
    public void rotate(int[] nums, int k) {
        k %= nums.length;
        reverse(nums,0,nums.length-1);
        reverse(nums,0,k-1);
        reverse(nums,k,nums.length-1);
    }
    public void reverse(int[] nums,int start,int end){
        int left =start;
        int right = end;
        while(left<right){
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```
### 思路
1.轮转k位置(```A=[1,2,3,4,5,6];B=[7,8,9]```) ```A+B = [1,2,3,4,5,6]+[7,8,9]```  
反转为```B+A=[7,8,9]+[1,2,3,4,5,6]```就相当于整体反转一次,```A```反转一次,```B```反转一次

## 16.除自身以外数组的乘积

``` java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] leftMul= new int[nums.length];
        leftMul[0]=1;
        for(int i=1;i<nums.length;i++){
            leftMul[i] =leftMul[i-1]*nums[i-1];
        }

        int[]  rightMul=new int[nums.length]; 
        rightMul[nums.length-1]=1;
        for(int i=nums.length-1-1;i>=0;i--){
            rightMul[i] =rightMul[i+1]*nums[i+1];
        }

        int[] ans = new int[nums.length];
        for(int i=0;i<nums.length;i++){
            ans[i] = leftMul[i]*rightMul[i];
        }
        return ans;            
    }
}
```
### 思路
使用类似前缀和的思想,用一个数组存放自身左侧数值的乘积,  
再用另一个数组存放自身数值右侧的乘积(```left[0]=1,right[n-1] = 1```)  
数组对应元素相乘即为最终结果

## 17.缺失的第一个正数##
``` java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n=nums.length;
        for(int i =0;i<n;i++){
            while(1<=nums[i] && nums[i]<=n &&nums[i]!=nums[nums[i]-1]){ // nums[i]!=nums[nums[i]-1]:当前位置与要换的位置的元素值不能相同
                                                                        // 不必担心无限循环,如果缺少了当前位置需要的元素,那么不断交换终会拿到1<=nums[i] && nums[i]<=n 不满足这个条件的值
                int j=nums[i]-1;
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
            }
        }
        for(int i = 0;i<n;i++){
            if(nums[i]!=i+1){
                return i+1;
            }
        }
        return n+1;
    }
}
```
### 思路
解题步骤:
___换座位___:不需要满足数值在```[1,n+1]```的范围内  
有 n 个学生坐在教室的座位上，把 ```nums[i]```当作坐在第 i 个座位上的学生的学号。  
我们要做的事情，就是让学号在 1 到 n 中的学生，都坐到编号与自己学号相同的座位上（学号与座位编号匹配）。  
学号不在``` [1,n] ```中的学生可以忽略  
### 总结
```java
while(1<=nums[i] && nums[i]<=n &&nums[i]!=nums[nums[i]-1])
// 1 nums[0],2 nums[1],i nums[i-1]
//1.不在[1,n]中的学生可以忽略
//2.nums[i]!=nums[nums[i]-1] 而不是i!=nums[i]-1可以避免重复元素如[1,1,2]
//当i = 1时,i!=nums[i]-1 需要交换元素,从而无限循环
//而nums[i]==nums[nums[i]-1] 跳过这次循环
```
