## 160.相交链表 ## 
```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if(headA==null||headB==null) return null;//一条链为空，直接返回 null。
        ListNode a =headA;                       //a =链表 A 的头，开始走
        ListNode b =headB;                       //b =链表 B 的头，开始走
        while(a!=b){                             //while没相遇，继续走
            a=a==null?headB:a.next;              //a还没走到null，继续走，走完跳headB
            b=b==null?headA:b.next;              //b同理
        }
        return a;
    }
}

```
### 思路
1. a 走完 A 后，换道去走 B;  b 走完 B 后，换道去走 A; 循环结束的唯一条件是：a == b
2. 为什么一定能相遇？  
   - A 的独有长度 = x
   - B 的独有长度 = y
   - 公共相交部分长度 = c
那么：
  - a 走的路径：A 全程（x+c） + B 全程（y+c）
  - b 走的路径：B 全程（y+c） + A 全程（x+c）
  - 两者总步数都是 x+y+2c，步数一样。
  - 当它们都把“对方的独有长度”补齐后，就会在公共部分的起点（相交点）同时进入并相遇。 


## 206.反转链表#
```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre =null;//反向指向
        ListNode cur=head;//当前指针，负责走
        ListNode tmp=null;//防断链
        while(cur!=null){
            tmp=cur.next;
            cur.next=pre;
            pre=cur;
            cur=tmp;
        }
        return pre;
    }
}
```

### 思路 
- 三指针
- （存 tmp）→（反 cur.next）→（接 pre）→（走 cur）


## 234.回文链表

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        if(head==null||head.next==null) return true;
        //第一步：快慢指针找到中间节点
        ListNode slow = head;
        ListNode fast = head;
        while(fast.next!=null&&fast.next.next!=null){//注意这个的终止条件
            fast=fast.next.next;
            slow=slow.next;
        }
        //此时slow为中间节点，将其后链表 反转（存反接走）
        ListNode secHead = slow.next; //后半段头指针
        ListNode pre = null;
        while(secHead!=null){
            ListNode tmp = secHead.next;
            secHead.next = pre;
            pre = secHead;
            secHead = tmp;
        }
        //前链表与已反转链表依次比较
        secHead=pre;  //pre是反转后的新头
        slow=head;
        while(slow!=null&&secHead!=null){
            if(slow.val!=secHead.val){
                return false;
            }
            slow =slow.next;
            secHead=secHead.next;
        }
        return true;
    }
}
```
### 思路  
- **边界**：0/1 个节点一定是回文
- **快慢指针找中点**：把链表分成前半段、后半段
- **反转**后半段：存反接走
- **对比两段**：一一比较值是否相同
- 返回结果
### 注意条件
- if(head==null||head.next==null)//判边界
- while(fast.next!=null&&fast.next.next!=null)//让 slow 落在“左中点”
- while(secHead!= null)//反转后半段链表
- while(secHead!= null)//比较时用后半段控制

## 141.环形链表
```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        if(head==null) return false;
        ListNode fast =head;
        ListNode slow =head;
        while(fast!=null&&fast.next!=null){
            fast=fast.next.next;
            slow=slow.next;
            if(fast==slow){
                return true;
            }
        }
        return false;
    }
}
```
### 思路  
- 判环和234回文链表中“找（左）中点”思想一样：fast走两步，slow走一步
- 判环的while (fast != null && fast.next != null) { ... }是让slow落在右中点，并且在循环里检查“fast == slow”

## 142.环形链表II
```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode fast = head;
        ListNode slow = head;
        while(fast!=null&&fast.next!=null){
            fast = fast.next.next;
            slow = slow.next;
            if(fast==slow){//判环，找到相遇点fast
                slow = head;//从头和相遇点同步走找到入口
                while(fast!=slow){
                    fast = fast.next;
                    slow = slow.next;
                }
                return slow;
            }
        }
        return null;
    }
}
```
### 思路
1. 先判环并找到相遇点fast
2. 再slow从头和相遇点fast同步走找到入口。  


## 21.合并两个有序链表
```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0);//虚拟头，不讨论第一个节点是list1还是2
        ListNode pre =dummy;//新链表的“尾指针”，永远指向已经合并好的链表的最后一个节点

        while(list1!=null&&list2!=null){
            if(list1.val<list2.val){ //比较节点，接更小的
                pre.next =list1;
                list1=list1.next;
            }else{
                pre.next=list2;
                list2=list2.next;
            }
            pre=pre.next;
        }
        pre.next=list1==null?list2:list1;//如果 list1 空了，就把 list2 剩余接到后面；否则把 list1 剩余部分接到后面

        return dummy.next;
    }
}
```
### 思路
1. 先判环并找到相遇点fast
2. 再slow从头和相遇点fast同步走找到入口。

## 2.两数相加
```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);//虚拟头，方便处理第一位
        ListNode pre=dummy;
        int  sum=0;//当前位的和
        int more=0;//进位
        while(l1!=null||l2!=null||more>0){  //l1、l2都有节点、还有进位
            sum=(l1==null?0:l1.val)+((l2==null?0:l2.val))+more;  //如果某条链表已经到头了，当前位就当 0
            more=sum/10;  //算进位
            sum%=10;  //保留当前位
            ListNode node =new ListNode(sum);//把当前位生成节点，接到结果链表
            pre.next=node;
            pre=node;
            l1=l1==null?null:l1.next;//没到头就往后走，到头就保持 null
            l2=l2==null?null:l2.next;
        }
        return dummy.next;
    }
}
```

## 25.k个一组反转链表
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || head.next == null){
            return head;
        }
        //定义一个假的节点。
        ListNode dummy=new ListNode(0);
        //假节点的next指向head。
        // dummy->1->2->3->4->5
        dummy.next=head;
        //初始化pre和end都指向dummy。pre指每次要翻转的链表的头结点的上一个节点。end指每次要翻转的链表的尾节点
        ListNode pre=dummy;
        ListNode end=dummy;

        while(end.next!=null){
            //循环k次，找到需要翻转的链表的结尾,这里每次循环要判断end是否等于空,因为如果为空，end.next会报空指针异常。
            //dummy->1->2->3->4->5 若k为2，循环2次，end指向2
            for(int i=0;i<k&&end != null;i++){
                end=end.next;
            }
            //如果end==null，即需要翻转的链表的节点数小于k，不执行翻转。
            if(end==null){
                break;
            }
            //先记录下end.next,方便后面链接链表
            ListNode next=end.next;
            //然后断开链表
            end.next=null;
            //记录下要翻转链表的头节点
            ListNode start=pre.next;
            //翻转链表,pre.next指向翻转后的链表。1->2 变成2->1。 dummy->2->1
            pre.next=reverse(start);
            //翻转后头节点变到最后。通过.next把断开的链表重新链接。
            start.next=next;
            //将pre换成下次要翻转的链表的头结点的上一个节点。即start
            pre=start;
            //翻转结束，将end置为下次要翻转的链表的头结点的上一个节点。即start
            end=start;
        }
        return dummy.next;


    }
    //链表翻转
    // 例子：   head： 1->2->3->4
    public ListNode reverse(ListNode head) {
         //单链表为空或只有一个节点，直接返回原单链表
        if (head == null || head.next == null){
            return head;
        }
        //前一个节点指针
        ListNode preNode = null;
        //当前节点指针
        ListNode curNode = head;
        //下一个节点指针
        ListNode nextNode = null;
        while (curNode != null){
            nextNode = curNode.next;//nextNode 指向下一个节点,保存当前节点后面的链表。
            curNode.next=preNode;//将当前节点next域指向前一个节点   null<-1<-2<-3<-4
            preNode = curNode;//preNode 指针向后移动。preNode指向当前节点。
            curNode = nextNode;//curNode指针向后移动。下一个节点变成当前节点
        }
        return preNode;
    }
}
```
