## 19.删除链表的倒数第N个节点
```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy=new ListNode(0);
        dummy.next =head;
        ListNode fast =dummy;
        ListNode slow =dummy;
        for(int i=0;i<n;i++){
            fast=fast.next;
        }
        while(fast.next!=null){
            slow=slow.next;
            fast=fast.next;
            
        }
        if(slow.next!=null){
            slow.next=slow.next.next;
        }
        return dummy.next;
    }
}
```
### 思路
- 快慢指针 fast、slow 都从 dummy 出发
- 先让 fast 走 n 步
- 然后 fast 和 slow 一起走，直到fast.next == null；slow 会停在倒数第n个节点的前一个节点。
- 删除操作就是跳过目标节点：slow.next = slow.next.next

  ## 24.两两交换链表中的节点
```java
  class Solution {
    public ListNode swapPairs(ListNode head) {
        if(head==null||head.next==null) return head;
        ListNode first=head;
        ListNode second=head.next;
        ListNode res=swapPairs(second.next);
        second.next=first;
        first.next=res;
        return second;
    }
}
```
### 思路：
- 把“交换后面的部分”交给递归，当前只负责交换前两个并把结果接起来。
