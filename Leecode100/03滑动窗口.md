# 滑动窗口
## 8.无重复字符的最长子串  
``` java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int ans =0;                                    //ans=0
        int left =0;                                   //左窗0
        Map<Character,Integer> map = new HashMap<>();  //map<char字符，int出现次数>
        char[] chars = s.toCharArray();                //字符串转数组
        for(int i=0;i<chars.length;i++){               //for右窗0
            map.merge(chars[i],1,Integer::sum);        //map.merge(chars[右])
            while(map.get(chars[i])>1){                //while chars[右]的次数>1，则重复
                map.put(chars[left],map.get(chars[left])-1);
                                                       //就缩小窗口->减少 chars[左] 的次数
                left++;                                //左窗自增
            }
            ans = Math.max(ans,i-left+1);              //ans为ans和右-左+1 取最大
        }
        return ans;
    }
}
```
### 思路  
使用滑动窗口,左边不动,右边不断遍历,用一个``HashMap<Character,Integer>``存储元素出现个数  
如果当前元素出现个数大于了1就表明 有重复元素,  
然后左端点不断移动 将``HashMap``的值-- 直到这个元素的个数等于一 继续右端点移动  
### 总结 
``map.merge(chars[i],1,Integer::sum);`` 若不包含``chars[i]``,则values=``1``,若包含则 ``新values``为``values``与``1``求和  
merge(k, 1, Integer::sum) 的意思是：如果 k 不存在：放进去并设为 1
                                   如果 k 已存在：把旧值和 1 相加（次数 +1）

## 9.找到字符串所有字母异位词
``` java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int[] cntP = new int[26];                  //两个26长度的int数组
        int[] cntS = new int[26];                  //分别存字符(索引)在字符串、当前窗口出现的次数(值)
        List<Integer> ans = new ArrayList<>();     //构造arrayList的ans

        for(char c:p.toCharArray()){               //for循环，字符串p转为数组并给cntP赋值
            cntP[c-'a']++;
        }

        for(int right=0;right<s.length();right++){ //for右窗0
            cntS[s.charAt(right)-'a']++;           //字符串s右窗字符入cntS
            int left = right-p.length()+1;         //定位左窗：左=右-p.length()+1
            if(left<0){continue;}                  //if continue到左=0
            if(Arrays.equals(cntS,cntP)){          //if当前窗口cntS和给定串cntP的分布相同
                ans.add(left); }                        //左窗加入ans：ans.add(left)           
            cntS[s.charAt(left)-'a']--;            //字符串s左窗字符出cntS
        }
        return ans;
    }
}
```
### 思路
字母异位词的判断方式有两种  
1. 用``int[26]``记录每个字母出现次数,若``Arrays.equals(cntS,cntP)``则为异位词  
2. 将异位词重排: ``char[] cs = s.toCharArray()`` ``Arrays.sort(cs)`` 若重排后相等则为异位词  
本题若用方法二则需要从s中分割出来判断,比较麻烦,最好使用方法一  
通过滑动窗口不断移动 右进左出
### 总结 
```java

for(char c:p.toCharArray()){
            cntP[c-'a']++;
}// 方法一常规流程 统计各个字母出现个数
```
